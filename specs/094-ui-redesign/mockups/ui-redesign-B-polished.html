Couverture du design system

  • Lumières light_onoff light_dimmable light_color — pattern icon + slider + power button (haut de page)
  • Volets shutter + gate + pool_cover — pattern slider + state badge + segmented ↑■↓ (haut de page et Portail ci-dessus)
  • Capteurs sensor — pattern icône + valeur + state badge (haut de page). Niveau batterie déplacé vers le monitoring batteries dédié.
  • Thermostat thermostat heater pool_heat_pump — pattern courant + target +/- + power (ci-dessus)
  • Énergie energy_meter main_energy_meter energy_production_meter — pattern read-only avec valeur en amber/vert (ci-dessus)
  • Météo weather weather_forecast — pattern multi-valeur inline (ci-dessus)
  • Télécommandes button + switch — pattern read-only avec dernier événement (ci-dessus)
  • Eau water_valve — pattern read-only valeur + chip ouvert/fermé + power button (ci-dessus)
  • Pompes piscine pool_pump — utilise le pattern shutter ou power-only selon le hardware
  • Médias media_player + appliance — utilise le pattern icon + name + chevron (déjà mocké dans la section Multimédia)

Tous les patterns réutilisent les mêmes briques visuelles : .eq__icon tinté par catégorie, .eq__name truncable, plus des cellules spécifiques (slider, power-btn, shutter-grp, chip-state, battery, therm-target, energy-val, forecast-row). Aucun type d'équipement ne demande de nouveau pattern.

2 palettes à comparer

  • Hybrid — fond gris neutre (zinc), ocean blue, amber Sowel pour les lumières, ardoise pour les volets, sauge pour les capteurs. L'ambre reste un accent, plus une dominante.
  • Dark — variante nuit : fond slate sombre, mêmes accents en versions claires. À envisager comme mode complémentaire, pas remplacement.

Ce qui reste identique entre les 2

  • Layout : sidebar identique, top bar, hero strip 4-cell, actions, grid 2-col avec colonne droite
  • 3 ajouts UX : Mode actif highlight, Recipe detail card, Activity feed
  • Headers de catégorie tintés (couleur dérivée de chaque palette)
  • Indicateur ⚡ pour les équipements pilotés par recette/mode
  • Bouton power coloré quand allumé
