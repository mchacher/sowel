Le bouton « Connecter » d'une intégration

Deux défauts vus en branchant un plugin Tesla : le bouton s'appelle « Connecter avec Samsung » pour tous les plugins, et « Démarrer » devient « Remplir les champs requis » sans dire lequel. À gauche ce qui existe, à droite la proposition. Les deux panneaux sont manipulables : tape dans les champs, enregistre, connecte.

Partir de :

Aujourd'hui

Le libellé est celui de SmartThings ; le champ manquant n'est nommé nulle part.

Proposé

Le nom du plugin dans le bouton ; le champ manquant nommé et marqué ; « Connecter » enregistre d'abord.

Ce qu'on change

  • « Connecter à Tesla » : le nom vient du plugin, pour tous les plugins OAuth.
  • « Démarrer » garde son nom. Sous les boutons : « Il manque : Domaine », cliquable, qui amène au champ.
  • Le champ obligatoire vide est bordé de rouge dès qu'on a enregistré ou quitté le champ.
  • Des modifications non enregistrées ? Le bouton devient « Enregistrer et connecter à Tesla ».

Ce qu'on ne change pas

  • La disposition du panneau, les cartes d'état, le bouton Enregistrer.
  • Les règles de validation propres à un plugin (l'identifiant de la borne est vérifié par le plugin, qui lève une alarme).
  • SmartThings : son bouton devient « Connecter à SmartThings ».

Arbitrages

  • A1 — « Enregistrer et connecter » quand le formulaire a changé, plutôt que de griser le bouton ? Recommandé : oui.
  • A2 — Marquer en rouge seulement après un enregistrement ou une sortie de champ (pas à l'ouverture) ? Recommandé : oui.
